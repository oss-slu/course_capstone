## Description

**Teams** negotiate working agreements so that expectations are explicit and conflicts have a reference point.

**Instructor** monitors team discussions and reviews agreement submissions so that teams with unclear norms get guidance.

## Acceptance Criteria

- [ ] Slack monitored for working agreement discussions
- [ ] Agreement submissions reviewed
- [ ] Teams with vague agreements followed up
- [ ] 1:1 scheduling reminder sent

## Stretch AC (Agreement Quality)

- [ ] All teams submit working agreements
- [ ] Agreements address communication, meetings, code review, collaboration
- [ ] Teams reference agreements in subsequent discussions

## Notes
